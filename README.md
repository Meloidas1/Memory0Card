# 🧠 Quiz Legend: Omega Max

Quiz Legend: Omega Max is a Python PyQt5-based quiz game with RPG-style progression, modern UI, and multiple game modes. It turns a simple quiz into a full game experience with levels, coins, power-ups, and a shop system.

---

## 🎮 Features

- Campaign, Survival, and Time Attack modes  
- XP, Level, and Rank system (D → S+)  
- Coins and shop system  
- Power-ups (50/50, Freeze, Skip)  
- Lives and streak system  
- Timer-based questions  
- Save/load progress (JSON)  
- Animated UI effects  

---

## 💎 Game Systems

- 🧠 Quiz engine with multiple-choice questions  
- 🏆 Ranking system based on performance  
- 🛒 Shop with usable items  
- 💾 Persistent player data  
- 🔥 Combo/streak rewards  

---

## 🛠️ Built With

- Python 3  
- PyQt5  
- JSON storage  

---

## 🚀 Goal

This project demonstrates how a simple quiz app can be upgraded into a full interactive game using GUI programming and game logic design.
